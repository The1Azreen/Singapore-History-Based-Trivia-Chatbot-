# Singapore History-Based Trivia Chatbot

This project is a trivia chatbot powered by a large language model (LLM). It is designed to engage users in interactive conversations about Singapore's rich history, providing educational and entertaining trivia.

## Features
- **Interactive Conversations**: Users can ask questions or participate in trivia games about Singapore's history.
- **LLM-Powered**: The chatbot leverages advanced natural language processing to provide accurate and context-aware responses.
- **Custom Dataset**: A curated dataset of Singapore's historical events, figures, and landmarks is used to enhance the chatbot's knowledge base.

## Instuction
1. Clone the repository (excluding the dataset, which is not pushed to GitHub).
2. Install the required dependencies.
3. Run the chatbot application and start interacting.

## Note
The dataset used for training the chatbot is not included in this repository to comply with data privacy and copyright policies. The repository will not provide said dataset to adhere to copyright laws.
